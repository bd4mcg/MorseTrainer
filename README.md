# CW 电键训练室（静态 Web Serial 版）

运行时不需要 Node.js、串口桥接程序或后端 API。串口由访问网页的电脑上的浏览器读取。

## 部署

将 static-site 目录内的文件全部上传到普通静态网站，配置 HTTPS，用桌面 Chrome 或 Edge 访问。支持部署在网站子目录。不要上传整个开发目录（包含旧版备份）。不要直接双击 index.html：模块和 TXT 题库需要通过网页服务加载。

本机预览：双击 start.cmd（仅此预览方式需要已安装 Python），访问 http://localhost:8082/。云端部署不需要 Python。原有 Node.js 服务无需启动。

## 电键

设置 → 电键与串口中可勾选“模拟测试 · 空格拍发”。关闭设置后点击开始练习，无需串口即可按空格或拍发按钮练习；此选项会保存在 Cookie 中，取消勾选后恢复串口模式。

首次点击开始练习或设置内的电平检查，在浏览器窗口选择 COM 口。后续可以直接打开已授权串口。浏览器不向网页提供 COM 号码，网页用授权序号及 USB 标识显示；换端口时选择“选择其它串口…”。多个相同型号适配器应在浏览器选择窗口核对端口。

手键公共端接 RTS（DB9 7 脚），输入端选择 CTS（8）、DSR（6）或 DCD（1），按下电平可设高/低。程序打开串口后关闭硬件流控、设置 RTS，DTR 为低，并连续读取电平。设置内电平检查显示采样次数、最大间隔和各脚变化次数。开始时先松键，释放稳定后才记录。停止练习、退出设置会关闭串口。不要让旧版程序或其它串口软件占用同一端口。

网页须在前台；浏览器采样不是硬实时，计时精度受系统负载、USB 驱动和浏览器调度影响。界面显示最大采样间隔供核对。当前使用 3ms 稳定消抖，保留首次观察到变化的时间。

## 题库与设置

callsign.txt：每行一个呼号。
qcodes.txt、cw_terms.txt、sentences.txt：每行“发送内容 | 中文含义”，支持 # 注释。均为 UTF-8。上传修改后的 TXT 即可更新；刷新页面或重新选择该练习模式加载。

练习设置保存为 Cookie，设置内可清除。串口授权由浏览器管理，清除设置 Cookie 不会撤销授权，可在浏览器网站权限中撤销。

## 验证记录（2026-10-16）

自动化测试 52 项通过（包含训练回归及串口底层接口模拟）。涵盖 CTS/DSR/DCD、高低有效电平、RTS/DTR、消抖、取消授权、连接途中停止、读取异常、关闭释放。
实物测试：用户确认 COM4 电键有效；页面实际记录 6250 次读取、CTS 68 次变化，最大采样间隔 11.2ms。已验证关闭设置断开、开始练习重新连接、停止练习断开及空格拍发。DSR/DCD 的真实硬件接线未测试，已覆盖模拟测试。

开发测试可用 node --test；Node.js 仅用于开发测试，部署目录没有 Node.js 依赖。根目录保留旧版后端源代码作回溯，不属于静态部署包。

旧版完整源码备份：backups/nodejs-working-20261016.zip。
官方 API 说明：https://developer.chrome.com/docs/capabilities/serial

## 自由练习

练习模式选择“自由”，不出固定题目、不自动换题。支持串口手键和模拟空格输入，实时显示识别结果，按设定速度检查点划及间距。点划按实测长度归类（2 个点时长为分界），不能判断原本想发的字符。标准条按每次实发起点对齐；松键后点击“清空记录”可继续，单轮上限 200 个点划。自由模式不播放本题标准码。
